# Totem de autoatendimento: demonstração

Demonstração para apresentar o totem de autoatendimento no celular, tablet ou computador:
**https://gabrielbernarde.github.io/totem-demo/**

- Roda inteira no navegador: sem servidor, sem cadastro.
- **Pagamento simulado:** nada é cobrado.
- Os pedidos ficam só no aparelho e navegador de quem está testando.
- Administração: PIN `1234`.

Este repositório contém apenas os arquivos publicados da demonstração.
